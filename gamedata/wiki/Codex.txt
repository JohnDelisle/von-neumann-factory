= Codex =
== Overview ==

The Codex provides information about Shapez 2 gameplay, machines, and goals.

The Codex is accessed with the 'Codex' hotkey (default 'G') or by clicking on the question mark in the upper right hand corner.

The Codex has a list of topics. Each topic has several pages.  There is a search input field and forward and back buttons for navigation.

All of the hotkeys listed in the Codex are automatically updated based on the hotkeys set in the game settings.
