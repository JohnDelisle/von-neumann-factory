== Overview ==

The Fluid Mixer takes two fluids and mixes them according to the mixing tables. The total fluid volume is maintained.  For example, 60L of each input color results in 120L of the output color.

Fluid color mixing tables are here: [[Fluids#Mixing Tables|Mixing Tables]]

== Specifics ==

Fluid must be supplied to both inputs in order for the Mixer to produce an output.  Both inputs are consumed equally.  The amount of fluid produced is exactly the same amount of fluid as was consumed in total from both the inputs.

If the color of one of the inputs changes color, the input buffer attached to that input will drain the old color before filling with the fluid of the new color.
