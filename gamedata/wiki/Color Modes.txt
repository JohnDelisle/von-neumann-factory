= Color Modes =
== Overview == 

Shapez 2 has 4 <span class="gl">Color Modes</span>:

* RGB: This is the default color mode. The basic colors are red, green and blue. For information on mixing these colors, see [https://en.wikipedia.org/wiki/RGB_color_model RGB color model in Wikipedia].
* RYB: The basic colors are red, yellow and blue. For information on mixing these colors, see [https://en.wikipedia.org/wiki/RYB_color_model RYB color model in Wikipedia].
* CMYK: The basic colors are Cyan, Magenta, Yellow. For information on mixing these colors, see [https://en.wikipedia.org/wiki/CMYK_color_model CMYK color model in Wikipedia].
* RGB (Colorblind): Increases contrast of the default RGB colors and adds patterns.

The color mode can be selected in the general settings and controls how colors are displayed on [[Shapes]] and Fluids. It is worth noting that the change is only visual and doesn't affect what the colors actually are internally, this can be seen with [[Shape Codes]], fluid signals in [[Signal Producer]]s, or [[Fluid Producer]]s.
