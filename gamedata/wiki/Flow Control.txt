== Belt Filter ==

The Belt Filter routes the flow of shapes.  It has two outputs:
* <span style="color:green">✔</span> straight through
* <span style="color:red">✘</span> to the side
Which output the shapes are passed to depends on the [[Wire]] input signal.

{| class="wikitable" 
! Signal !! Filter Result
|-
| Null || Blocks belt (shapes do not move)
|-
| Conflict || Blocks belt (shapes do not move)
|-
| Integer = 0 || <span style="color:red">✘</span> - All shapes
|-
| Integer ≠ 0 || <span style="color:green">✔</span> - All shapes
|-
| Shape || <span style="color:green">✔</span> - Shapes matching the shape signal <br> <span style="color:red">✘</span> - Shapes not matching the shape signal
|-
| Color || <span style="color:red">✘</span> - All shapes
|}

== Pipe Gate ==

The Pipe Gate limits fluid throughput depending on the [[Wire]] input signal.

{| class="wikitable" 
! Signal !! Filter Result
|-
| Null || Blocks Fluids (No throughput)
|-
| Conflict || Blocks Fluids (No throughput)
|-
| Integer = 0 || Blocks Fluids (No throughput)
|-
| Integer ≠ 0 || Allows Fluid throughput
|-
| Shape || Blocks Fluids (No throughput)
|-
| Color || Allows Fluid throughput if the fluid matches the input color signal.
|}
