== Overview ==

The Item Producer produces a full belt of any shape.

== Specifics ==

The Item Producer is unlocked with cheat commands, see [[Sandbox]].

After placing the Item Producer, select it and select the <span class="gl">Configure</span> button to enter the desired [[Shape Code]]. The shape code can have [[Shapes#Different Numbers of Parts per Layer and More Layers | any number of parts per layer and any number of layers]].
