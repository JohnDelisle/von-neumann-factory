== Overview ==

The Label displays text on [[Machine Platforms]].

After placing the Label, select it and select the <span class="gl">Configure</span> button to enter the desired text.

== Specifics ==

Labels support any characters, and the [https://docs.unity3d.com/Packages/com.unity.textmeshpro@3.2/manual/RichTextSupportedTags.html Unity Text Mesh Pro Rich Text Tags] can also be used.
