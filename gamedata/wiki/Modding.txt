= Modding =
== Overview ==

Modifications (mods) are user-created changes to the game.  They can be anything, such as a new quality of life (qol) tool, new items (machines, platforms) to use, or completely new features.

Shapez2 uses Unity game framework (6000.3.19f1).  The game natively supports loading mods, so no external mod loader is needed.  The developers have provided documents and sample code to help modders understand the source code and develop new content.  There is also a modding API available: [https://github.com/tobspr-games/shapez2-shifter ShapezShifter].

Mods are published to the [https://steamcommunity.com/app/2162800/workshop/ Steam Workshop], where they can be browsed by players and automatically downloaded by the game.
