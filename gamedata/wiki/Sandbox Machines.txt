= Sandbox Machines =
__NOTITLE__
{{Machines}}
= {{PAGENAME}} =
Sandbox machines infinitely produce resources. To unlock them, you have to [[Debug Console#cheats.enable | enable cheats]] and unlock the hidden upgrade for sandbox machines, which can be done with the commands [[Debug Console#research.unlock-all | research.unlock-all]], [[Debug Console#god | god]], or [[Debug Console#research.set | research.set]] with <code>CBSandbox</code>. Note that enabling cheats can have unwanted effects, see all details in [[Debug Console#cheats.enable | cheats.enable]]. This isn't an issue if it's done in a sandbox save (different save from your main save).
