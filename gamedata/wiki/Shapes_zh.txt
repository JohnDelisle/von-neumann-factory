= Shapes/zh =
== 概述 ==

形状是异形工厂2的核心元素。它们可以被开采、切割、上色等等。

每个"形状"都由"层级"组成，每个层级都由被游戏中称为"象限块"的部件组成，每个部件都有各自的类型和颜色。在常规[[Scenarios|场景]]中，每层包含4个象限块，而在六分场景中，每层包含6个象限块。在疯狂场景中，单个形状可能有1到5个层级，而在其他场景中则是1到4个层级。

== 形状代码 ==

形状可以用形状代码来表示。形状代码是一串字符，可以在游戏内或游戏外轻松转移。

每个层级从下到上依次排列，并用冒号（<code>:</code>）分隔，层级中的每个象限块由两个字符组成，第一个是形状类型，第二个是颜色。一个层级中的所有象限块从右上角开始，按照顺时针次序依次排列，中间不加分隔符。

形状类型和颜色的字符代码可在上表的 "代码 "栏中找到。对于标记为 "可带颜色 "的形状类型，颜色字符为上表中的颜色字符之一，否则为<code>-</code> 。

== 形状查看器 ==

通过形状查看器，你能够以三维方式观察形状，还可以更改观察角度，并有多种分割象限块和/或层级的选项。在用户界面中任意位置点击一个形状即可打开。

== 单层不同块数和更多层数 ==

游戏支持单层的部件数量和/或层数多于当前[[Scenarios|场景]]中的形状。 但是，形状中的所有层必须具有相同的块数。它们可以在形状查看器、[[地图#地图标记|地图标记]]' 形状和[[蓝图库|形状蓝图图标]]中输入和查看。

使用外部工具，它们可以出现在传送带和信号线上。只要多个入口的建筑物接收到的形状各层中的块数相同，所有建筑物都能正常工作。

== 形状重力规则 ==

形状有重力规则。与[[Shapez 1|异形工厂1]]相反，异形工厂2中不存在悬空层级/象限块。

这些规则会在任何可能产生悬空象限块的操作后应用。

=== 定义 ===

如果形状部件直接相邻（对角/夹角不算），且两个部件都不是针销，它们就被认为是水平连接在一起的。

如果形状部件
* 位于形状的底层
* 或直接位于有支撑的部件上方 
* 或跟有支撑部件水平连接 
* 或是一个晶体且直接位于有支撑的晶体下方
则被认为有支撑。

=== 流程 ===

从下往上，每一层都会被分割为多个由水平相连的部件所构成的组。

然后，对于每个组，如果所有部件都没有支撑，该组便会开始下落，从而导致组内所有晶体被摧毁；并且如果晶体起到了连接常规部件的作用，该组可能会分裂成多个组。

这些组会持续下落，直到其至少有一个部件的正下方有另一个部件为止。

== 针销 ==

针销的行为与常规形状类型相似，但有几点不同。

它们通常被视为代替空缺的支撑物，以允许制造一些原本会有悬空部件的形状。

因此，如果一个形状用针销替换了其中非顶部的空缺，那么这个形状会被[[Vortex|漩涡]]接受。

反过来，如果一个形状用空缺替换了其中非顶部的针销，那么这个形状也会被漩涡接受。

针销通过一种特殊方式生成，即通过[[Pin Pusher|顶针器]]。

针销不会与形状部件发生水平连接，这意味着它们不会支撑水平相邻的形状部件，如果那些部件没有被其他任何东西支撑，它们就会下落。

然而，它们仍然会支撑正上方的形状部件。另请参阅[[#形状重力规则 | 形状重力规则]]。

与空缺部件类似，针销在[[Crystal Generator|晶体生成器]]中会被[[#晶体|晶体]]所替换。

此外，针销没有颜色。它们在通过[[Painter|上色器]]时不会发生任何变化。

== 晶体 ==

晶体的行为与常规形状类型不同，这使得解锁它们时会面临一项新的挑战。

它们的规则可以概括为一个事实：晶体易碎。

它们通过一种特殊方式生成，即通过[[Crystal Generator|晶体生成器]]。

一条通用规则是，当一个晶体破碎时，所有与之相连的晶体会一同破碎。

当晶体在同一层上直接相邻（对角/夹角不算），或当它们在彼此正上方/正下方时，就被认为是相连的。

颜色不同和/或非同时生成的晶体，只要符合上述规则，仍被视为相连。

晶体只要下落就会破碎。

这种情况可能发生在其位于[[Stacker|堆垛机]]的顶部形状中，或者在其他操作中（例如在[[Cutter|切割机]]中）因[[#形状重力规则|重力]]而下落。

但其他形状部件可以安全地落到晶体上。

如果一个晶体与另一个相连的晶体部件分离，它也会破碎。

这种情况可能发生在[[Cutter|切割机]]或[[Half Destroyer|半破机]]中。

剧透警告：下一个例子是关于“如何在一个形状中获得上方没有任何东西的针销”的解决方案，你可能更希望先自己探索出答案。

{{spoiler|这种情况也可能在[[Pin Pusher|顶针器]]中发生：当一个晶体部件因层数限制被丢弃，而它又与下方的另一个晶体部件相连时。}}

然而，一个晶体部件可以安全地与一个相连的非晶体形状部件分离。

此外，晶体一旦生成便无法改变颜色。

它们仍然可以穿过[[Painter|上色器]]和[[Crystal Generator|晶体生成器]]，但会保持原样。
