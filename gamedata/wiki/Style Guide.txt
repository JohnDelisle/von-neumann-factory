= Style Guide =
== Generated Pages ==

This wiki contains some pages (such as the list of blueprint and milestone shapes) that are generated by using a script.  These pages have template names prefixed with "Auto-Gen" should not be modified manually as those changes would be overwritten.

The page generation scripts and instructions can be found here: [https://github.com/Loupau38/shapez-2-tools/tree/main/wiki%20page%20auto%20gen wiki page auto gen]

== Shape Render Tool ==

This wiki has a built-in tool to render shapes.  This tool should be used whenever possible to display images of shapes.  The tool is split in three parts:
* The template (with instructions): [[Template:ShapeRender]]
* The on-wiki script: [[MediaWiki:Common.js]]
* The remote script: [https://loupau38.github.io/assets/scripts/shapeViewer.js renderShape script]

== Terminology ==

* <span class="gl">Shape parts</span> should be used instead of 'quadrants' when referring to something that applies to both regular and hexagonal shapes.
* Preferably, <span class="gl">layers</span> should be used for shape layers and <span class="gl">levels</span> for machine/space levels (previously floors).
* If it doesn't hurt understandability, objects in the game (machines, platforms, etc.) should be referred to by their in-game name (example: <span class="gl">Cutter</span> instead of 'full cutter', <span class="gl">Swapper</span> instead of 'halves swapper', etc.). Exceptions are possible however, like <span class="gl">Bent Stacker</span> instead of <span class="gl">Stacker (Bent)</span>, etc.

== Images ==

For images in [[:Category:Building Images]] and [[:Category:Platform Images]] : for the best quality, the camera values should be set via save editing to :
* Position (X and Y) : rounded to <code>.0</code> or <code>.5</code>
* Zoom : <code>4.0</code> for machines, <code>70.0</code> for platforms
* Rotation : <code>0.0</code>
* Angle : <code>50.0</code>
